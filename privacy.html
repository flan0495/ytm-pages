プライバシーポリシー

最終更新日：2026年11月22日

1. このツールについて

YoutubeMack（以下「本ツール」）は、YouTube チャンネルの運営者本人が、自分のチャンネルに動画をアップロードするために使う内部ツールです。本ツールは YouTube API サービスを利用しています。

2. 取得する情報

本ツールが Google アカウントへのアクセスで扱うのは、運営者本人のアカウントについての次の情報だけです。

  • 動画をアップロードするための権限（YouTube Data API の youtube.upload）
  • アップロード先が正しいチャンネルかを確認するための、チャンネル名などの基本情報（youtube.readonly）

運営者以外の方の個人情報は取得しません。

3. 利用目的

取得した情報は、運営者本人のチャンネルへの動画のアップロードと、アップロード先の確認にのみ使います。広告、分析、販売などの目的には使いません。

4. 保存と共有

認証情報は運営者が管理する作業環境にのみ保存し、第三者に共有・販売しません。

5. 権限の取り消し

本ツールに与えた権限は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。取り消すと、本ツールは保存した認証情報を使えなくなります。

6. YouTube と Google のポリシー

本ツールは YouTube API サービスを利用しています。利用にあたっては YouTube 利用規約 が適用され、データの取り扱いには Google プライバシーポリシー が適用されます。

7. お問い合わせ

本ポリシーに関するお問い合わせは、YouTube チャンネルの概要欄に記載の連絡先までお願いします。
